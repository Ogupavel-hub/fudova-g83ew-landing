# FUDOVA G83EW — локальный лендинг

Откройте `index.html` в браузере или запустите из папки проекта:

```bash
python3 -m http.server 8080
```

Затем перейдите по адресу `http://localhost:8080`.

Изображения кофемолки подгружаются с официальной страницы FUDOVA; поэтому для их отображения нужен интернет.
